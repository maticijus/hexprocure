# Security policy

## Supported versions

Only the latest release and the current `main` branch receive security fixes.

| Version | Supported |
|---|---|
| latest 0.x release | yes |
| older releases | no |

## Reporting a vulnerability

Do not open a public issue. Email security@hexprocure.dev (placeholder,
founder confirms) with a description, affected version and steps to reproduce.
We acknowledge within 3 business days.

## Disclosure

We follow 90-day coordinated disclosure. We aim to ship a fix inside 90 days of
your report and publish an advisory with credit to you, unless you prefer to
stay anonymous. If a fix is not ready after 90 days, you may disclose.

## Bug bounty

There is no bug bounty yet. We credit reporters in the advisory and the changelog.
